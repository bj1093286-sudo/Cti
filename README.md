# CTI 통화 대시보드

아웃바운드 상담원의 발신 통화 기록(CTI)을 집계해 보여주는 웹 대시보드입니다. Python 표준 라이브러리와 SQLite만 사용하며 별도 설치가 필요 없습니다(Python 3.10+). 차트는 `static/vendor/chart.umd.js`(Chart.js 4.4.1, MIT)를 내장해 오프라인에서도 동작합니다.

## 실행

```bash
python -m scripts.seed_demo --reset   # 데모 데이터(상담원 6명, 최근 70일 통화, 오늘 녹취 WAV 24개)
python -m cti.app                     # http://127.0.0.1:8080
```

데모 계정: `admin / admin1234`(관리자), `viewer / viewer1234`(조회 전용)

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `CTI_DB` | `data/cti.db` | SQLite 파일 |
| `CTI_SYNC_ROOT` | `data/sync` | 녹취 동기화 폴더 루트 (`<루트>/<상담원 이름>/...`) |
| `CTI_BACKUP_ROOT` | `data/backup` | 백업 zip 저장 위치 (`<루트>/<상담원ID>/<시각>.zip`) |
| `CTI_HOST`, `CTI_PORT` | `127.0.0.1`, `8080` | 바인드 주소 |
| `CTI_INGEST_INTERVAL` | `300` | 녹취 폴더 자동 적재 주기(초), 0이면 끔 |

## 메뉴 1: 대시보드

- **필터**: 오늘 / 어제 / 이번 주 / 이번 달 / 직접 지정(최대 367일), 상담원. 선택값은 브라우저에 기억됩니다.
- **직전 동일 기간**: 오늘↔어제, 이번 주(월~오늘)↔지난주 월~같은 요일, 이번 달(1일~오늘)↔지난달 1일~같은 날짜(말일 초과 시 말일), 직접 지정↔바로 앞 같은 일수.
- **KPI**: 총 통화 건수, 총 통화시간, ATT, 고객 수(빈 번호 제외 중복 제거), 짧은 통화 비율. 증감은 %로, 비율 지표는 %p로 표시합니다.
- **정의** (`settings.min_call_sec`, 기본 10초)
  - 처리 건수 = `duration_sec >= min_call_sec` 인 통화 수
  - ATT = 처리 건수 기준 통화의 `duration_sec` 평균
  - 짧은 통화 = `duration_sec < min_call_sec`
  - 총 통화 건수/총 통화시간/일별 추이/시간대 분포는 전체 통화 기준
- **일별 상담원 처리건수**: 행=상담원, 열=날짜, 브랜드 블루 농도 히트맵, 행·열 합계.
- **상담원별 실적**: 처리건수, 총 통화시간, ATT, 최장 통화 — 열 제목 클릭으로 정렬.
- **차트**: 일별 통화량 추이(범례 클릭으로 상담원별·합계 선 토글), 0~23시 통화 분포.
- **설정 메뉴**: `min_call_sec`(0~600초), 용량 기반 추정 비트레이트 변경, 녹취 적재 현황과 "지금 가져오기". 관리자만 저장할 수 있고 조회 계정은 읽기 전용입니다. 바꾸면 과거 기간을 포함한 모든 집계에 즉시 적용됩니다.
- **상담원 드로어**: 처리건수 추이, 최근 통화 20건. 관리자에게만 동기화 폴더 현황, "백업 후 동기화 폴더 비우기", 백업 이력이 보입니다.

### 백업 후 비우기 동작

1. 폴더의 녹취 파일을 먼저 통화 기록으로 적재(지운 뒤에는 기록을 만들 수 없음)
2. 동기화 중(최근 1분 내 수정)인 파일을 뺀 목록을 고정한 뒤 zip으로 묶음
3. zip 무결성(`testzip`)과 파일 수를 검증
4. 검증 통과 시 **고정해 둔 파일만** 삭제(작업 중 새로 들어온 파일은 유지), 폴더 자체는 유지
5. 이력 기록(일시, 파일 수, 용량, 실행자, zip 경로)

동기화 폴더가 `CTI_SYNC_ROOT` 밖을 가리키면 거부합니다. 같은 상담원에 대한 동시 실행도 막습니다.

## 녹취 파일 → 통화 기록 적재

녹취 파일 1개 = 통화 1건입니다.

```
CTI_SYNC_ROOT/
  김민지/                                   ← 최상위 폴더 이름 = 상담원 (처음 보면 자동 등록)
    통화 녹음 010-1234-5678_261012_103015.m4a
    01098765432_20261012_104500.wav
```

- **시작 일시**: 파일 이름의 `YYYYMMDD_HHMMSS`, `YYMMDD_HHMMSS`, `YYYY-MM-DD HH-MM-SS`, `YYYYMMDDHHMMSS`
- **고객번호**: 파일 이름의 전화번호(`010-1234-5678`, `01012345678`, `+82 10 …`, 지역번호)
- **통화시간**: WAV·M4A/MP4/3GP·MP3는 헤더의 재생 길이, 그 외 형식은 `파일 크기 ÷ 비트레이트`(설정에서 변경)
- 일시를 못 읽은 파일은 적재하지 않고 설정 화면에 목록으로 보여 줍니다.
- 최근 1분 안에 수정된 파일은 동기화 중으로 보고 다음 회차로 미룹니다.
- 같은 파일은 두 번 적재되지 않습니다.
- 자동(5분 주기), 설정 화면의 "지금 가져오기", 백업 후 비우기 직전에 적재합니다.

### 개인정보

전화번호 원문은 DB에 저장하지 않습니다.
- `customer_masked`: 화면 표시용 `010-****-5678`
- `customer_key`: DB별 비밀키로 만든 HMAC — 고객 수(중복 제외) 집계용, 원래 번호로 되돌릴 수 없음
- 파일 경로도 번호가 들어 있으므로 HMAC(`source_key`)으로만 저장하고, 화면의 실패 목록도 마스킹합니다.

단, 녹취 파일 자체(동기화 폴더·백업 zip)의 파일 이름에는 원래 번호가 남아 있으니 폴더 접근 권한은 따로 관리해야 합니다.
